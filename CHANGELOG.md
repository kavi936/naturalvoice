## [0.1.0] — 2026-08-16

### Added

- **Ambient Layer** — `AmbientMixer` Pipecat processor with restaurant/office profiles
- **Turn Manager** — scaffold (`turn_manager.py`) for three-state conversational model
- **Speech Renderer** — scaffold (`speech_renderer.py`) for spoken-register markup
- Demo scripts: `run_demo.py` (ambient on) vs `run_baseline.py` (ambient off)
- Research: *The Voice Agent Naturalness Problem: A Layered Analysis* (v0.1)
