## How to cite

If you reference this work, use:

```bibtex
@misc{naturalvoice2026,
  title        = {The Voice Agent Naturalness Problem: A Layered Analysis},
  author       = {naturalvoice contributors},
  year         = {2026},
  howpublished = {\url{https://github.com/kavi936/naturalvoice/tree/main/research}},
  note         = {Open research document, v0.1}
}
```

## Contributing research

Open an issue or PR if you have:

- New citations on turn-taking, backchannels, or vocal uncanny valley
- Benchmarks or evaluation frameworks for conversational naturalness
- Observations from production voice agent deployments
